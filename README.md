# senkyo_e_go
■サービス概要
議員や法案の“見える化”アプリ。議員の発言や法案提出などの活動履歴を可視化し、AIで要点をやさしく解説。推し議員の特徴をレーダーチャートで分析し、似ている議員をレコメンド。とっつきやすくして、政治をもっと身近に、楽しく理解できます。

■このサービスへの思い・作りたい理由
日本の経済や社会が厳しさを増す中、若者の政治離れと低投票率に強い危機感を抱き、政治をエンタメ化して分かりやすく伝えるアプリを開発したいと考えています。実際の活動に関わる提出法案や国会での発言を基に、AI解説、ビジュアルなどで議員や法案をやさしく解説し、生活への影響もシミュレーション。政治資金の流れや支持団体の分かるリンクを追加することで、議員の背景を調べるきっかけ作りにもなります。推し議員の登録や通知機能で日常的に政治に触れ、政治を“自分ごと”として捉えるきっかけをつくります。

■　ユーザー層について
社会や生活に不満があるが政治には無関心、または社会問題や選挙への関心が芽生えたばかりだが、何から調べていいか分からない若者（高校生〜30代）層。

■　サービスの利用イメージ
・トップページにアクセスすると、ポップでエンタメ感のあるUIで「政治って堅苦しそう…」というイメージを払拭するカジュアルで親しみやすいデザインを表示。
・気になるワードで検索でき、オートサジェスト付き検索窓で、トレンドワード・関心テーマを自然に誘導。検索結果に「関連法案」や「話題に多く言及した議員」が表示。
・関連法案をタップするとAIの解説ページを表示
　　・法案要点：4コマ漫画風ストーリー形式（出来れば）で表示
　　・法案の可決・反対状況（文字列タップでや法案テキストを表示する）
　　・あなたの生活にどんな影響があるかをシミュレーション。「この法案が通ると、あなたの生活はこう変わる！」をシナリオ形式で提示（例：「あなたの年収で年間〇万円増税」）
・気になる議員をタップして議員ページを表示。以下の情報を提供：
    ・プロフィールと活動履歴：提出法案、国会発言、youtube、SNSポスト、法案の可決・反対状況、法案要点で表示
    ・AIで解説：過去の発言や法案の要点をエンタメ的にストーリー仕立てで分かりやすく表示するとともに。
    ・反対意見ナビ機能：法案に反対の意見を持つ議員・団体の「なぜ賛成・反対しているのか？」をAIが要約して中立に提示
    ・政治資金・支持団体をリンク先で検索可能：政治資金収支報告書のデータベース（https://political-finance-database.com/）へのリンク先で「誰からお金が流れているか」「どの団体とつながっているか」が一目で分かる
    ・レーダーチャート：教育／福祉／経済などその議員の関心分野を可視化
    ・SNS発信・動画：議員のX（旧Twitter）やYouTubeでの公式発言まとめ表示。一般人による議員に関連するSNSでの言及や反応動画・ツイートも表示（※アルゴリズムにより収集／自動分類）
・「推し議員」に登録すると、推し議員登録可能（ログイン不要で保存はローカル）／アカウント作成で通知ONに対応。また「あなたの推しと似た議員」機能で類似志向・類似発言の議員を自動レコメンドを表示


■　ユーザーの獲得方法
・URLをSNSで共有できる
・オンラインで、参加者にツールの使い勝手を体験してもらい、口コミでの拡散を促進。

■　サービスの差別化・推しポイント
・デザイン／UI：ポップで直感的、ストーリー形式も導入
・機能性／分かりやすさ：議員の分析をアイドルのようにレーダーチャートで可視化。法案もストーリー形式や漫画調で紹介、AI要約で気軽に理解できる設計
・双方向性：議員レーダーチャート、法案診断、影響シミュレーション結果をシェア可能であり、一般人による議員関連SNS・YouTube投稿を自動収集・表示
・情報と生活の接続性：生活影響シミュレーションで“自分ごと化”

■　機能候補
【MVPリリース】
・キーワード検索（オートサジェスト付き）
・法案提出・法案賛成反対・国会発言の履歴リスト
・発言や法案内容のAI要点解説＋テキスト表示
・政治資金の流れ／支持団体の表示（政治資金収支報告書データベースへのリンク先表示）
・推し議員登録機能（ログイン不要・ローカル保存）・「推しと似た議員」レコメンド（簡易）
・議員のX（旧Twitter）・YouTube公式アカウントの埋め込み表示
・各ページ（URL付き）・議員のプロフィールと活動履歴のSNS投稿機能

【本リリース】
・反対意見ナビ（法案に反対する議員・団体の理由をAI要約）
・生活影響シミュレーション
・レーダーチャート表示
・法案の漫画風ストーリー解説（4コマ or 簡易ストーリー）
・ログイン機能（SNSログイン or メール）
・推し議員の活動通知（発言・法案提出）
・一般人によるSNS・動画の議員関連投稿の自動収集＆表示

■機能の実装方針（予定）
・反対意見ナビ（反対者の理由を中立的に要約）
　・国会会議録API（例：国会API、議員ウォッチ）で対象議案を検索・発言を抽出（キーワードフィルタ）はStimulus Autocomplete（Rails7 ）でオートコンプリートを使用
　・AIによる要約＋中立変換（AIは無料使用枠内）
　・発言収集＋要約処理はActiveJob＋Sidekiqで非同期処理
・議員の類似度レコメンド
　・発言内容 → 分かち書き＋TF-IDFスコア算出（treat, tf-idf-similarity など）
　・Cosine類似度でスコア計算（Ruby処理 or Redisキャッシュ化）
・SNS・YouTubeの一般投稿表示
　・X連携：X API　→ Twitter API v2 の「Essential」プランで月1500件制限付きを利用
　・YouTube連携：YouTube Data API で議員名検索＋動画タイトル・説明文で分類
